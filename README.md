# FileSimulator v2 UI Preview

Versión mejorada de la app estática para analizar consumos eléctricos desde Excel.

## Archivos principales

- `index.html`
- `styles.css`
- `app.js`

## Mejoras incluidas

- Menú lateral profesional
- Drag & drop para subir Excel
- Modo oscuro / claro
- Dashboard ejecutivo
- Insights automáticos
- Curva de carga
- Punta / Llano / Valle
- Reactiva Q1
- Heatmap horario
- Rankings
- Exportación CSV
- Carpeta `versions/v1/` con copia de la versión estable anterior
